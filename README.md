# Portfolio

Sitio portfolio estático listo para correr en local.

## Ejecutar

Con Python 3:

```bash
python3 -m http.server 3000
```

Luego abre: <http://localhost:3000>

## Estructura

- `index.html`: estructura principal del sitio.
- `styles.css`: estilos globales y tema claro/oscuro.
- `script.js`: comportamiento básico (año dinámico y cambio de tema).
